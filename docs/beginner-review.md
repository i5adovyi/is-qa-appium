# Complete-beginner review — 21 October 2026

## Assessment

The original course supplies strong mobile foundations and unusually detailed
workplace practice. Its opening still assumes someone can operate an editor
and terminal, follow a typed function and distinguish a test from a program.
That makes it approachable for a newcomer to automation, but a steep first
experience for someone also new to programming and testing.

This review adds preparation for those prerequisites. It does not remove or
renumber the original course. Suitability is an editorial assessment supported
by executable-example checks; it is not a usability study with novice learners
or a guarantee of employment/readiness within a fixed number of weeks.

## Gaps and additions

| Gap found | Addition | Evidence the learner should produce |
|---|---|---|
| Opening prerequisites already assume editor/terminal fluency | [Computer basics](handbook/computer-basics.md), B1–B3 | Locate the root; save and run a changed file; restart the reader |
| The first-hour/four-week routes can imply unrealistic pacing from zero | [Start from zero](handbook/start-from-zero.md), eight short sessions | One repeatable small result per session; explicit readiness checks |
| Several syntax concepts appear together in lesson 02 | [Programming first steps](handbook/programming-first-steps.md), P1–P8 | Predict values, branches, object/array access, missing values and assertion outcomes |
| Test vocabulary and negative-case meaning need more groundwork | [First test workbook](handbook/first-test-workbook.md), T1–T4 | Independent expectations, a boundary defect caught, honest device evidence |
| Choosing a lab file and reading starter failures can be confusing | [First lab coach](handbook/first-lab-coach.md), C1–C3 | Own implementation, understood feedback and an extra contract-based case |
| Hosted reading may be mistaken for a code execution environment | Explicit reader/editor/terminal distinctions and command anatomy | Run code in the local project and distinguish it from reading online |
| New support material could be hidden deep in the library | Dashboard/sidebar entry, workbench entries and links from lessons/labs | Reach the preparation route directly from the homepage |

The 18 preparation exercises have tasks, acceptance criteria, hints/review
guidance and prerequisite/execution limits. They supplement the existing
16 lessons, 48 lesson exercises, 12 coding labs and 100 indexed workplace/
interview items. They are not extra auto-graded labs or extra completion boxes.
All original starters, reference implementations, mobile specs and personal
progress remain intact. Full answers are not copied into learner files.

## Remaining teaching limits

The added route still needs practice and feedback. It is not a full computer
literacy course or a complete JavaScript reference. A true beginner may need
several attempts before combining concepts. Windows/Linux installation and
device-specific blockers need observation on those actual environments.

Use one small task, inspect the learner's attempt, and ask for a prediction
before adding difficulty. Record confusion encountered during real learning
sessions and improve that precise step instead of adding more topics at once.
