# Sauce Labs learner specs

Create your own `*.spec.ts` files here using the shared
[assignment template](../assignment.template.ts). This folder is outside the
default reference suite. Follow the [training-app guide](../../../docs/handbook/training-apps.md)
to download the pinned APK and run one explicitly chosen file.

Keep your attempts in separate files. The `reference/` subdirectory contains two
maintainer compatibility checks for cart behavior and session reset; running
them does not complete your assignment. The guide includes their exact command.
